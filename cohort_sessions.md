# OpenSTAAD Automation Cohort — Session Overview

---

## Week 1 — Programming Foundations

### Session 1 — Setup + Visual Studio
Install Visual Studio and configure your development environment. Learn the essential setup steps to start writing C# code immediately.

### Session 2 — Variables, Loops & Conditions
Master variables to store data, loops to repeat actions, and conditions to make decisions. Write your first complete programs using these core building blocks.

---

## Week 2 — From Programming to Automation

### Session 3 — OOP Concepts
Master classes and objects — the building blocks of professional C# development and automation tools.

### Session 4 — File Handling + Mini Project: 2D Frame Generator
Learn to read, write, and manipulate files in C# — essential for STAAD input file automation. Build a 2D PEB Frame Generator: your first real automation tool that creates STAAD models from code.

---

## Week 3 — OpenSTAAD

### Session 5 — Introduction to OpenSTAAD + API Workflow + Mini Project: MTO Tool
Get started with OpenSTAAD fundamentals — how the API connects to STAAD.Pro and enables programmatic control over your models. Master the API workflow from initialization to execution, including geometry automation and creating models through code. Build an MTO Generation Tool to automate material take-off extraction directly from your STAAD models.

### Session 6 — Supports & Loads
Learn to automate support assignments and load applications in STAAD models programmatically using C# and OpenSTAAD.

---

## Week 4 — Real Automation

### Session 7 — Extracting Results + Mini Project: Load Export Tool
Master techniques for extracting analysis results, reactions, and member forces directly from STAAD using the OpenSTAAD API. Build an Export Tool that automatically extracts loads and reactions from STAAD and exports them to Excel spreadsheets.

### Session 8 — Drawing Automation
Make STAAD draw for you. Use C# to create a real structural drawing from code — turning model data into an actual drawing instead of redrawing it by hand. Your first working drawing, built by programming.

---

## Week 5 — AI & MCP + ETABS

### Session 9 — AI + STAAD MCP Server
Connect STAAD.Pro to AI. Understand what Model Context Protocol (MCP) servers are, set one up, and let an AI assistant read and drive your STAAD model — writing working OpenSTAAD functions for you in minutes instead of hours.

### Session 10 — ETABS Automation
Take the same automation mindset beyond STAAD. Learn how to connect to ETABS through its API and start automating your ETABS workflow, with a live walkthrough of basic automations. Same idea as OpenSTAAD — different software, same superpower.
